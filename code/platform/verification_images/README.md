# Verification and demonstration images

These 12 files are **byte-identical copies** of images from the completed research: Dataset v1 **validation** split and
the frozen Experiment 4 FLUX.1-schnell set. **No TEST-split image is included.** They serve two purposes:

1. **Start-up self-check.** Every time the platform starts, it re-scores all 12 images and compares them with the scores
   saved during the research (`expected_scores.csv`). It refuses to start if any score differs by 1e-4 or more, or if
   any decision changes.
2. **Demonstration.** The "Analyse bundled verification images" button runs them through the platform.

| Group | Files | Why |
|---|---|---|
| Authentic camera-trap (Caltech) | 2 | Authentic examples, incl. a night IR image |
| Authentic citizen-science (iNaturalist, CC0) | 3 | Authentic examples; one is a real **detector disagreement** |
| SDXL synthetic | 3 | Synthetic examples; one is a real **detector disagreement** |
| FLUX.1-schnell synthetic | 4 | Held-out-generator examples; one real **disagreement**, and one image that **both detectors call REAL** (a known limitation) |

- **Scores:** `expected_scores.csv` holds the saved research scores at full precision, the frozen thresholds, the
  expected decisions and status, the SHA-256 of each file, and the source file of each score.
- **Selection:** the images were chosen from saved predictions only. No model was run to select them, and they
  are not a statistical sample.
- **Licences:** see `ATTRIBUTION.csv`. The Caltech images are shared under CDLA-Permissive-1.0 (text in
  `../licenses/`); the iNaturalist photos are CC0 (checked per photo on 2026-09-29); the SDXL and FLUX images were
  generated by the project and are labelled as AI-generated.
- **Metadata:** none of the files contains EXIF or GPS metadata. They were not modified in any way.

`expected_scores.csv` was built from the saved prediction files by `verification/dev_tools/build_expected_scores.py`
on the development machine.
